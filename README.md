# GUIOSAD — Procesos

Repositorio del proyecto **GUIOSAD v2**: migración de la herramienta de análisis
de adopción de software FLOSS desde una app monolítica (Python + flexx) a una
arquitectura desacoplada **Django REST + React**.

El código fuente de la aplicación está en [`GUIOSPRO_FLOSS-main 2/`](./GUIOSPRO_FLOSS-main%202/README.md).
